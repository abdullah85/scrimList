ScrimList Usage Information

First visit the required course on Scrimba, say The Full Stack Developer Path for example.

To render the number for each lesson check if the icon is on, displayed and reload the page.

To disable numbering, ensure the icon is off, displayed as and reload the page.

Activate

The numbers are displayed before each Topic with a separator.

Deactivate

The page is reset to the original text without the numbers.
